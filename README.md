# Muhammad Raveel Jamil — Portfolio

## Requirements
- Node.js 18 or newer
- npm
- Git

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
npm run preview
```

## Deploy to GitHub Pages
This project is configured for `https://raveel1202-jpg.github.io/Portfolio/`.

1. Ensure the repository is `raveel1202-jpg/Portfolio`.
2. Push your source files to the `main` branch.
3. Run:
   ```bash
   npm run deploy
   ```
4. In GitHub, open **Settings → Pages** and select **Deploy from a branch**, branch `gh-pages`, folder `/(root)`.
